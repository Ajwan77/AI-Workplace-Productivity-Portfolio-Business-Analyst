# Verification Checklist — Business Analyst

## Verification Checklist

Before using AI-generated information, I check the following:

- Identify exactly what information needs to be verified.
- Check whether the output is supported by the original source.
- Verify facts, names, dates, and numbers when they are included.
- Look for missing or unsupported information.
- Check that AI has not invented details.
- Compare important claims with the available source.
- Document any issues found before using the final output.
- Make the final decision myself after verification.

## Worked Example

### Output Being Verified

The AI-generated action item from the Information Workflow section was:

| Action Item | Owner | Deadline | Priority | Status |
|---|---|---|---|---|
| Review the current onboarding process | [Not Specified] | [Not Specified] | [Not Specified] | [Not Specified] |

### Verification Process

**1. Identify:**  
I checked the action item against the original meeting notes.

**2. Set Criteria:**  
The action item must be directly supported by the meeting notes, and missing details must not be invented.

**3. Test:**  
The notes state that the current onboarding process needs further analysis and should be reviewed. However, they do not specify an owner, deadline, priority, or status.

**4. Confirm and Decide:**  
The action item is supported by the source. The missing fields were correctly marked as [Not Specified].

## Verification Result

The output passed the verification check because the action item was supported by the original information and no missing details were invented.
